# AgroTech Space

**Do espaço para o campo: tecnologia que cultiva o futuro.**

## Sobre o Projeto

O **AgroTech Space** é uma plataforma web desenvolvida para conectar tecnologias espaciais ao agronegócio, utilizando dados de satélites e inteligência artificial para auxiliar produtores rurais na tomada de decisões estratégicas.

O projeto foi desenvolvido como solução para a **Global Solution FIAP 2026/1**, cujo tema é **A Economia Espacial**, demonstrando como a exploração espacial e os dados orbitais podem gerar impactos positivos na agricultura, na sustentabilidade e na segurança alimentar.

## Problema

O agronegócio enfrenta diversos desafios relacionados ao monitoramento das lavouras e às mudanças climáticas.

Entre os principais problemas estão:

- Falta de previsibilidade climática;
- Secas e enchentes inesperadas;
- Desperdício de água e insumos;
- Dificuldade no monitoramento de grandes áreas agrícolas;
- Redução da produtividade devido à tomada de decisão tardia.

Muitos produtores só identificam problemas quando os prejuízos já ocorreram.

## Solução

O **AgroTech Space** utiliza informações obtidas por satélites para monitorar áreas agrícolas e apresentar dados de forma simples, intuitiva e acessível.

A plataforma oferece:

- Monitoramento climático;
- Índice de vegetação;
- Controle da umidade do solo;
- Alertas preventivos;
- Recomendações inteligentes;
- Visualização de dados espaciais.

Dessa forma, produtores rurais conseguem agir preventivamente e aumentar sua produtividade.

## Funcionalidades

### Home

Apresentação do problema, da solução, dos benefícios da plataforma, do fluxo de funcionamento, do impacto estimado, dos próximos passos e da equipe responsável pelo projeto.

### Dashboard de Monitoramento

Painel com indicadores agrícolas simulados:

- Temperatura;
- Umidade do solo;
- Índice de vegetação;
- Status da plantação.

### Mapa Satelital

Visualização interativa da fazenda dividida em setores monitorados.

O usuário pode clicar em cada área para visualizar:

- Nome do setor;
- Temperatura;
- Umidade;
- Nível de risco.

### Central de Alertas

Sistema de notificações preventivas para:

- Seca;
- Geada;
- Baixa vegetação;
- Necessidade de irrigação.

### Recomendações Inteligentes

Simulação de uma inteligência artificial agrícola que gera sugestões de ações com base nos dados monitorados.
